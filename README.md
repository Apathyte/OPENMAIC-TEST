# OPENMAIC-TEST

Disposable, evidence-led evaluation of OpenMAIC as a medium for practical shopfloor training.

## Active pilot

**OFI Pilot 001 — Where Did This Number Come From?**

The pilot tests whether lived plant experience can be turned into a credible 25–35 minute workshop for two future digital/operational champions without flattening it into generic Industry 4.0 dogma.

By EOD, record exactly one verdict:

- **Proceed** — build the next two modules.
- **Proceed with conditions** — useful after named defects are fixed.
- **Park** — authoring or delivery creates more work than value.
- **Fork** — retain the learning concept but change platform.

Start with [the pilot runbook](pilots/openmaic-ofi-001/runbook.md). The full scope, ownership split and acceptance gates are in [the pilot work item](pilots/openmaic-ofi-001/README.md).

## Repository rule

Commit the sanitised brief, test evidence, decision and reusable learning assets. Never commit API keys, raw customer material, plant exports, screenshots containing customer data, tag lists, recipes, personal data, network information, or the upstream OpenMAIC checkout.
